The Jupyter notebook `d+id_different_rotations_xzyz_strontium_ruthenate_BdG.ipynb` generates the lattice Green's functions for the two impurity interference of a $d+id$ superconductor in Strontium Ruthenate, and then exports it to CSV files.

The Jupyter notebook `d+id_different_rotations_Wannier.ipynb` takes these CSV files, convolutes the lattice Green's function with Wannier function to generate the Green's function in the sublattice scale, and computes the TDOS.

The resulting figures are shown in Fig. 5 and Fig. 6 in the main text.


`d+id_xzyz_joint_first_second_order_lattice.ipynb` calculates the lattice Green's function and its contribution to the lattice level TDOS.
Here the second order contribution is artificially enhanced to demonstrate that the first and second order contributions are spatially separated, which means, no special Fourier filtering techniques are required to separate them.

The notebook `d+id_xzyz_joint_first_second_order_Wannier.ipynb` modulates the data with Wannier functions and plots it in the sublattice scale.

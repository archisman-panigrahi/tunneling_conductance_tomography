
`d+id_xzyz_single_impurity_lattice.ipynb` hosts the code to generate the lattice level TDOS for a single impurity in a $d+id$ superconductor realized in strontium ruthenate.

The notebook `d+id_single_impurity_Wannier.ipynb` convolutes these lattice level data with Wannier function to generate a TDOS with sublattice accuracy.

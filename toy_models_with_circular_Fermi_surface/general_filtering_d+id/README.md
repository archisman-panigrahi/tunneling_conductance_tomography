`d+id_filtering_hyperbola_from_total.ipynb` hosts the code to generate the 1st order + 2nd order contribution to QPI in a $d+id$ superconductor and then Fourier filters it to highlight the hyperbolic fringes.

`d+id_single_impurity_Friedel.ipynb` generates the Friedel oscillations around a single impurity.

These codes are utilized to generate Fig. 2 of the supplementary information.

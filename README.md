This repository hosts codes for `Tomographic imaging of superconducting order using
particle-hole interference, Proc. Natl. Acad. Sci. U.S.A. 123 (27) e2534730123, https://doi.org/10.1073/pnas.2534730123 (2026)`  by Archisman Panigrahi, Vladislav Poliakov and Leonid Levitov.

Each subdirectories contain readme files explaining the functions of the Jupyter notebooks contained therein.

You can find a preprint at https://arxiv.org/abs/2503.16168, and the published version is available at https://doi.org/10.1073/pnas.2534730123.

The code utilizes the Julia programming language.
